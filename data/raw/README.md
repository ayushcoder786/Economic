# Raw Data Directory (`data/raw/`)

This directory is reserved for unmodified, raw source files downloaded from official statistical portals.

## Expected Datasets
- **File Name:** `per_capita_nsdp_constant_2011_12.csv` (or `.xlsx`)
- **Primary Source:** Reserve Bank of India (RBI) - Handbook of Statistics on Indian States
- **Alternative Source:** Ministry of Statistics and Programme Implementation (MoSPI) - National Accounts Statistics
- **Metric:** Per Capita Net State Domestic Product (NSDP) at Constant (2011-12) Prices in INR
- **Base Year:** 2011-12

## Academic Integrity Rule
Do not modify files in this directory manually. All transformations, renaming, and reshaping must be executed reproducibly through the `python/clean_data.py` script.
