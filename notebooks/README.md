# Notebooks Directory (`notebooks/`)

This directory is intended for exploratory data analysis (EDA), rapid prototyping, and interactive visualizations.

## Planned Notebooks
- `01_exploratory_inspection.ipynb`: Initial inspection of raw tables, distribution plots, and outlier checks.
- `02_divergence_deep_dive.ipynb`: Interactive analysis of sigma and beta convergence metrics.

## College Best Practice
Production pipeline code lives in modular `.py` files inside the `python/` directory. Notebooks are used for scratch work and visual reporting, importing modular functions from `python/`.
